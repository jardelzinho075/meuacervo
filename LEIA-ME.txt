MEU ACERVO DONNA IDEIA — COMO PERSONALIZAR

1) Abra script.js e configure WHATSAPP_NUMBER com 55 + DDD + telefone.
   O número está vazio para evitar enviar clientes a um contato fictício.
2) No array KITS de script.js, modifique preco: null para um valor numérico,
   como preco: 250 (que aparece R$ 250,00). Não coloque "R$" nesse campo.
3) Para adicionar kits, copie um objeto do array, troque id, nome, categoria,
   preco, imagem, descricao e imagens.
4) A foto do Toy Story não foi anexada: salve uma imagem real em
   images/kits/toy-story.webp e altere imagem e imagens no script.js.
5) O anexo da Sininho veio duas vezes, então foi utilizado uma única vez.
6) Logo original tinha 150x150px. Foi ampliada com nitidez ajustada,
   mas não é uma reconstrução vetorial de alta resolução.
7) Instagram: altere INSTAGRAM_URL para a URL oficial, quando disponível.
8) Abra index.html no navegador ou publique toda a pasta em Vercel/Netlify.

Tecnologias: HTML, CSS e JavaScript puro, sem bibliotecas de UI ou backend.
